# Hod Ads

## Description

Un site web pour créer des affiches pour les évènements de l'association de jeux de société Heaven of Dice. La date est interchangeable, ainsi que le nom de l'event, la salle (le lieu).

## Différence

Plusieurs types d'affiche pour chaque évènement:

| Pôle                   | Couleur     | Exemples d'Event                      |
| ---------------------- | ----------- | ------------------------------------- |
| Jeux de Réflexion      | Blanc cassé | Echec, Go, Rubiks' Cube...            |
| TCG                    | Bleu        | MTG, Lorcana, One Piece...            |
| Jeux de société        | Orange      | Uno, Skyjo, Monopoly...               |
| JDR                    | Bleu/Vert   | Campagne...                           |
| Wargames               | Rouge       | Warhammer...                          |
| Poker                  | Vert        | Poker                                 |
| Mensonges et Trahisons | Noir        | Loup-Garou, Complot, Shadow Hunter... |

Chaque affiche doit contenir:

- Le nom du pôle
- Le nom de l'asso (HOD)
- Les couleurs violettes et du pôle
- Le logo d'HOD
- Le nom de l'event
- Le lieu (salle)
- La date ou recurrence (tout les mardi par exemple)

Le site doit permettre de build l'affiche et de l'exporter:

- format instagram
- format A4 paysage ou portrait

## Design

Soit créatif (tu peux utilier /impeccable par exemple)

Il faudrait deux types de design par pôle. Les design hebdomadaires, et les design "spéciaux" pour les event extraordinaire.
