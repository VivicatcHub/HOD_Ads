# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Vite + React + TypeScript (choisi par l'utilisateur). Site statique, aucun backend. Export côté client.

## Users

Membres du bureau et responsables de pôle de l'association de jeux de société Heaven of Dice (HOD). Ils préparent la communication de leurs évènements : une soirée hebdomadaire récurrente ou un évènement exceptionnel (tournoi, campagne, soirée spéciale).

## Product Purpose

Générer en quelques secondes une affiche cohérente avec l'identité HOD pour un évènement, puis l'exporter pour Instagram ou pour impression. Réussite : une affiche publiable sans passer par un logiciel de graphisme.

## Capabilities and Constraints

- 7 pôles, chacun avec sa couleur : Jeux de Réflexion (blanc cassé), TCG (bleu), Jeux de société (orange), JDR (bleu/vert), Wargames (rouge), Poker (vert), Mensonges et Trahisons (noir).
- Deux designs par pôle : hebdomadaire et spécial (évènement extraordinaire).
- Champs éditables : nom de l'évènement, lieu (salle), date ou récurrence (ex. « tous les mardis »), heure, description courte, prix / entrée. Les trois derniers sont optionnels.
- Chaque affiche contient : nom du pôle, nom de l'asso (HOD), couleurs violettes HOD + couleur du pôle, logo HOD, nom de l'event, lieu, date/récurrence.
- Formats : Instagram 1:1 (1080×1080), 4:5 (1080×1350), story 9:16 (1080×1920), écran Full HD 16:9 (1920×1080), A4 portrait, A4 paysage.
- Exports : PNG, JPG, PDF.
- Pas de commentaires dans le code, pas de tests, pas de CI/CD, pas de push.

## Brand Commitments

- Nom : Heaven of Dice, abrégé HOD.
- Logo : `logo.png`, phénix low-poly violet tenant des d20 bleus, fond transparent, éclats de cristaux violets.
- Violet HOD obligatoire sur chaque affiche, associé à la couleur du pôle.

## Evidence on Hand

- `logo.png` (640×708, PNG transparent).
- Aucun visuel d'affiche existant, aucune photo d'évènement fournie.

## Product Principles

- L'affiche d'abord : l'aperçu est la vérité, ce qui est vu est ce qui est exporté.
- Chaque pôle est reconnaissable de loin par sa couleur, chaque affiche reste reconnaissable comme HOD.
- Hebdomadaire = repère familier et sobre ; spécial = évènement qui doit se démarquer.
- Zéro friction : remplir quelques champs, choisir un format, exporter.
